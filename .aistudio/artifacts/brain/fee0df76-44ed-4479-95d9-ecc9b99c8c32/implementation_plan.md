- **การเข้าถึงโหมด Admin:** ตรวจสอบอีเมล `Nitichat38937@gmail.com` ร่วมกับระบบรหัสผ่านหลังบ้าน (Admin Secret Passcode Verification)

## 2. สถาปัตยกรรมระบบ (Architecture & Data Flow)

```
[ เกษตรกรทั่วไป ] ───> Calculator ───> [ LocalStorage: tipgrow_custom_crops ]
                               │
                               └───> Firestore: fertilizerCalculations (userId == auth.uid)

[ ผู้ดูแลระบบ ]   ───> ตรวจสอบ Email == Nitichat38937@gmail.com + Admin Passcode
                               │
                               ▼
                       [ Admin Dashboard ]
                               ├── สถิติภาพรวมระบบ & การวิเคราะห์เชิงเกษตร
                               ├── คลังประวัติผู้ใช้ทั้งหมด (All Firestore records)
                               │     - ค้นหาตามชื่อเกษตรกร / รหัสแปลง / ชนิดพืช
                               │     - ลบหรือส่งออกรายงานสรุป (Export CSV)
                               └── คลังพืชและสูตรปุ๋ย (Agronomy Formulas & Presets)
```

### การปรับปรุงความปลอดภัย Firestore (`firestore.rules`)
อนุญาตให้ Admin (`Nitichat38937@gmail.com`) สามารถอ่านและจัดการรายการในคอลเลกชัน `fertilizerCalculations` ทั้งหมดได้:
```rules
function isAdmin() {
  return isSignedIn() && request.auth.token.email == 'Nitichat38937@gmail.com';
}

match /fertilizerCalculations/{calcId} {
  allow read: if isSignedIn() && (resource.data.userId == request.auth.uid || isAdmin());
  allow create: if isSignedIn() && isValidId(calcId) && incoming().userId == request.auth.uid;
  allow update: if isSignedIn() && isValidId(calcId) && ((existing().userId == request.auth.uid && incoming().userId == request.auth.uid) || isAdmin());
  allow delete: if isSignedIn() && isValidId(calcId) && (existing().userId == request.auth.uid || isAdmin());
}
```

## 3. รายละเอียดการพัฒนาตามขั้นตอน (Implementation Steps)

### ขั้นตอนที่ 1: ระบบเพิ่มพืชในการคำนวณ (Custom Crop Feature)
- **สร้าง Modal เพิ่มพืชใหม่ (`AddCustomCropModal.tsx`):**
  - ชื่อพืชภาษาไทยและอังกฤษ, พันธุ์ที่ปลูก
  - ระยะปลูกและจำนวนต้น/ไร่เริ่มต้น
  - กำหนดระยะการเจริญเติบโต (1-4 ระยะ) พร้อมค่าเป้าหมาย N-P-K (กก./ไร่) และสูตรปุ๋ยสำเร็จรูปที่แนะนำ
  - ไอคอน/อีโมจิประจำพืช
- **เชื่อมต่อกับ `Calculator.tsx`:**
  - จัดเก็บและอ่านรายการจาก `localStorage` (`tipgrow_custom_crops`)
  - แสดงปุ่ม `+ เพิ่มพืชของฉัน` ในรายการเลือกพืช
  - ติดป้ายกำกับ "พืชกำหนดเอง" (Custom Crop Badge) พร้อมปุ่มแก้ไขหรือลบพืชของตนเองได้

### ขั้นตอนที่ 2: ระบบตรวจสอบสิทธิ์ Admin และ Modal ยืนยันรหัสผ่าน (`AdminAuthModal.tsx`)
- ปุ่มเข้าสู่ระบบ Admin ในเมนูโปรไฟล์ของผู้ใช้ หรือแถบ Header (แสดงเฉพาะเมื่ออีเมลตรงกับ `Nitichat38937@gmail.com`)
- ระบบป้อนรหัสผ่าน Admin เพื่อยืนยันการเข้าถึง (มีระบบซ่อน/แสดงรหัสผ่าน, ป้องกัน Brute-force ชั่วคราว)
- บันทึกสถานะเซสชัน Admin ภายในเครื่องอย่างปลอดภัย

### ขั้นตอนที่ 3: แดชบอร์ดหลังบ้าน Admin (`AdminDashboard.tsx`)
- **แท็บ 1: สถิติรวม & ประวัติผู้ใช้ทั้งหมด (All Calculations Management)**
  - ดึงข้อมูลทั้งหมดจากคอลเลกชัน `fertilizerCalculations` ใน Firestore
  - แสดง Metric Cards: จำนวนการคำนวณทั้งหมด, พื้นที่ปลูกรวม (ไร่), พืชที่ถูกคำนวณมากที่สุด, ปริมาณการประหยัดปุ๋ยรวม
  - ตารางประวัติ: วันที่คำนวณ, ผู้ใช้งาน/อีเมล, พืช, ระยะการเติบโต, ขนาดพื้นที่, สูตรปุ๋ย, พร้อมปุ่มดูรายละเอียดและปุ่มลบประวัติ
  - ช่องค้นหา (Search) และตัวกรอง (Filter by Crop, Province)
  - ปุ่มส่งออกข้อมูล CSV สำหรับทำรายงาน
- **แท็บ 2: คลังพืชและสูตรปุ๋ย (Crop & Fertilizer Reference Management)**
  - ดูสูตรปุ๋ยและธาตุอาหารเป้าหมายของพืชเศรษฐกิจหลักทั้ง 12 ชนิด
  - ดูสูตรแม่ปุ๋ยหลัก (46-0-0, 18-46-0, 0-0-60)
  - ข้อมูลค่าความอุดมสมบูรณ์ดินแต่ละจังหวัด

### ขั้นตอนที่ 4: การเชื่อมต่อ Navigation และการอัปเดตไฟล์
- อัปเดต `firestore.rules` และ `firebase-blueprint.json` สำหรับสิทธิ์ Admin
- อัปเดต `Header.tsx` และ `App.tsx` เพื่อรองรับแท็บ `'admin'`
- ตรวจสอบความถูกต้องด้วย `lint_applet` และ `compile_applet`
